## 🍿 المصادر العربية المدمجة (12 مصدراً متكاملاً)

تمت إعادة بناء وبرمجة خوارزميات الاستخراج والفهرسة من أفضل وأقوى المواقع العربية الرائدة:

1. 🎬 **إيجي ديد (EgyDead)**: مكتبة ضخمة تغطي أحدث الأفلام الأجنبية والعربية، المسلسلات، الأنمي، والأفلام المدبلجة مع دعم سيرفرات المشاهدة والتحميل.
2. 🎬 **فاصل إعلاني (FaselHD)**: أشهر موقع عربي لمتابعة الأفلام والمسلسلات والترجمات الاحترافية مع مشغلات متعددة الجودات.
3. 🎌 **ويت أنمي (WitAnime)**: المصدر العربي الأول للأنمي، حلقات متجددة أسبوعياً، أفلام أنمي، وأوفات بالجودة الكاملة.
4. 🎌 **أنمي فور اب (Anime4Up)**: تغطية شاملة لجميع مسلسلات وأفلام الأنمي المترجمة والمدبلجة مع سيرفرات متعددة (StreamWish, Mp4Upload, VidHide).
5. 📺 **شاهد فور يو (Shahid4u)**: مسلسلات عربية حصرية، مسلسلات تركية مدبلجة ومترجمة، وأفلام سينمائية حديثة.
6. 🎬 **توك توك سينما (TukTuk Cinema)**: تصنيفات خاصة لأفلام ومسلسلات المنصات العالمية (Netflix, HBO, Amazon) بجودة عالية.
7. 🎬 **سيما ناو (CimaNow)**: باقة واسعة من الأعمال العربية والتركية والعالمية.
8. 🎬 **توب سينما (TopCinema)**: قوائم أعلى الأفلام والمسلسلات تقييماً على IMDb مع سيرفرات مشاهدة مباشرة.
9. 🧸 **ستار ديما (StarDima)**: المتخصص في كرتون الأطفال، الأنمي المدبلج، ومسلسلات الكرتون الكلاسيكية والحديثة.
10. 🎌 **أنمي زد (Animezid)**: مكتبة أفلام ومسلسلات أنمي وكرتون مدبلجة ومترجمة.
11. 🌏 **عالم الدراما (DramaWorld)**: المتخصص في الدراما الكورية، الآسيوية، واليابانية المترجمة والمدبلجة.
12. 📺 **شوف لايف (ShoofLive)**: تغطية خاصة للمسلسلات الحصرية العربية والتركية وسيرفرات AlbaPlayer السريعة.

## ⏱️ طريقة التثبيت والاستخدام في أقل من دقيقة

### 1️⃣ التثبيت في تطبيق Stremio:
1. افتح تطبيق **Stremio**.
2. توجّه إلى أيقونة **الإضافات (Addons)** (رمز الأحجية 🧩).
3. اضغط على زر **تثبيت مباشر** في أعلى هذه الصفحة أو الصق الرابط التالي في خانة البحث:
   ```text
   https://zxr-stream.vercel.app/manifest.json
   ```
4. اضغط على زر **Install** ثم وافق على التثبيت.
5. استمتع بمشاهدة أي فيلم أو حلقة مسلسل وستظهر لك روابط سيرفرات **ZXR Stream** العربية فوراً!

### 2️⃣ التثبيت في تطبيق Nuvio:
1. افتح تطبيق **Nuvio**.
2. توجّه إلى **الإعدادات (Settings)** ← قسم **الإضافات (Plugins / Add-ons)**.
3. اضغط على خيار إضافة رابط مخصص **(Add Custom Manifest URL)**.
4. الصق الرابط:
   ```text
   https://zxr-stream.vercel.app/manifest.json
   ```
5. اضغط **Confirm / Add**، وستصبح جميع السيرفرات العربية متاحة للمشاهدة فوراً داخل Nuvio.

## 🛠️ التشغيل والنشر الذاتي (Self-Hosting & Deployment)

إذا كنت ترغب بتشغيل الإضافة محلياً على جهازك أو رفعها على خادمك الخاص مجاناً:

### أ) التشغيل المحلي (Node.js):
```bash
# استنساخ المستودع
git clone https://github.com/devilmancrybabyx/ZXR-stream.git
cd ZXR-stream

# تثبيت الحزم المطلوبة
npm install

# تشغيل فحص واختبار التوافق
npm test

# تشغيل الخادم
npm start
```
سيكون الخادم متاحاً على: `http://localhost:7000/manifest.json`

### ب) التشغيل عبر Docker:
```bash
# بناء حاوية دوكر
docker build -t zxr-stream .

# تشغيل الحاوية
docker run -d -p 7000:7000 --name zxr-addon zxr-stream
```

### ج) النشر المجاني بضغطة زر عبر Vercel أو Render:
- يحتوي المستودع على ملفي `vercel.json` و `render.yaml` جاهزين للنشر الفوري والسلس على أي استضافة سحابية بنقرة واحدة!
